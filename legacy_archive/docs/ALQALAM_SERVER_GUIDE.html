Step 4 — .htaccess File

Is content ko copy kar ke public_html/ems/.htaccess mein save karein: 

# AL Qalam EMS — Apache Config
Options -Indexes
RewriteEngine On

# .env ko kabhi public nahi hone dena — CRITICAL!
<Files ".env">
    Order allow,deny
    Deny from all
</Files>

# config.php bhi hide karein
<Files "config.php">
    Order allow,deny
    Deny from all
</Files>

# API routing — /students ko alqalam_backend.php per forward
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ alqalam_backend.php/$1 [QSA,L]

# CORS Headers
Header always set Access-Control-Allow-Origin "*"
Header always set Access-Control-Allow-Methods "GET, POST, PUT, DELETE, OPTIONS"
Header always set Access-Control-Allow-Headers "Content-Type, Authorization, X-Device-Type"

# Security Headers
Header always set X-Content-Type-Options "nosniff"
Header always set X-Frame-Options "SAMEORIGIN"
Header always set X-XSS-Protection "1; mode=block"

# Production: Errors hide karein
php_flag display_errors off
php_value error_reporting 0
php_value upload_max_filesize 10M
php_value post_max_size 10M

⚠️ Common Problems aur Solutions:

500 Error → .htaccess syntax galat hai ya PHP version mismatch. cPanel → PHP Version → 8.1 select karein.
403 Forbidden → File permissions. File Manager mein files select → Permissions → 644 set karein.
DB Connection Error → .env mein DB_USERNAME aur DB_DATABASE mein cPanel prefix check karein (cpanelusername_dbname format).
CORS Error → .htaccess upload hua? Headers properly lag rahe hain?

🔧 Nginx + SSL Setup

# Nginx config file banayein
sudo nano /etc/nginx/sites-available/alqalam-api

# Ye content paste karein:
server {
    listen 80;
    server_name api.alqalam.edu.pk;

    # Node.js ko forward karein
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';  ← Socket.io ke liye zaruri
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 60s;
    }
}

# Enable karein
sudo ln -s /etc/nginx/sites-available/alqalam-api /etc/nginx/sites-enabled/
sudo nginx -t  # OK aana chahiye
sudo systemctl reload nginx

# SSL Certificate (FREE — Let's Encrypt)
sudo certbot --nginx -d api.alqalam.edu.pk
# Email daalein → Agree → Y → HTTPS select karein

# Test:
curl https://api.alqalam.edu.pk/health  # ✅
