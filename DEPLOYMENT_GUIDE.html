🚀 Option 3: VPS Ubuntu (Professional Setup)

Node.js ke liye zaruri hai. DigitalOcean / Vultr / Contabo — $6–12/month

PHP + Nginx on VPS

# Ubuntu 22.04 per
sudo apt update && sudo apt upgrade -y
sudo apt install nginx php8.2-fpm php8.2-mysql php8.2-curl php8.2-mbstring -y
sudo apt install mysql-server -y

# MySQL setup
sudo mysql_secure_installation
sudo mysql -u root
CREATE DATABASE alqalam_db CHARACTER SET utf8mb4;
CREATE USER 'alqalam'@'localhost' IDENTIFIED BY 'StrongPass@2024';
GRANT ALL ON alqalam_db.* TO 'alqalam'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# Import database
mysql -u alqalam -p alqalam_db < alqalam_database.sql

# Files copy karein
sudo mkdir -p /var/www/alqalam
sudo cp alqalam_backend.php config.php .env /var/www/alqalam/
sudo chown -R www-data:www-data /var/www/alqalam

Nginx Config

sudo nano /etc/nginx/sites-available/alqalam

server {
    listen 80;
    server_name api.alqalam.edu.pk;
    root /var/www/alqalam;
    index alqalam_backend.php;

    location / {
        try_files $uri $uri/ /alqalam_backend.php$is_args$args;
    }
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }
    # .env ko public access se protect karo
    location ~ /\.env { deny all; return 404; }
}

sudo ln -s /etc/nginx/sites-available/alqalam /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# SSL with Certbot
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d api.alqalam.edu.pk

Node.js Install (VPS per)

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

Files Upload + Dependencies Install

mkdir /var/www/alqalam-node && cd /var/www/alqalam-node

#   alqalam_node_server.js
#   package.json
#   .env

# ✅ express, mysql2, jsonwebtoken, bcryptjs, socket.io etc.
3

PM2 se Run karein (Background + Auto-restart)

sudo npm install -g pm2

# Start
pm2 start alqalam_node_server.js --name alqalam-ems

# Server restart hone par auto-start
pm2 startup
pm2 save

# Status check
pm2 status
pm2 logs alqalam-ems
pm2 monit
4

Nginx Reverse Proxy (Node.js ke liye)

server {
    listen 80;
    server_name api.alqalam.edu.pk;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';   # Socket.io
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_cache_bypass $http_upgrade;
    }
}

sudo certbot --nginx -d api.alqalam.edu.pk  # SSL
5

EMS mein URL update karein

Browser mein EMS kholein → API Settings → URL set karein:

https://api.alqalam.edu.pk

📄 .htaccess (PHP ke liye zaruri)

Is file ko public_html/ems/.htaccess ke naam se save karein:

Options -Indexes
RewriteEngine On

# Security: .env ko hide karein
<Files ".env">
    Order allow,deny
    Deny from all
</Files>

# API routing — /auth/login ko backend.php per forward karo
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ alqalam_backend.php/$1 [QSA,L]

# CORS Headers (agar PHP mein na ho)
Header set Access-Control-Allow-Origin "*"
Header set Access-Control-Allow-Methods "GET, POST, PUT, DELETE, OPTIONS"
Header set Access-Control-Allow-Headers "Content-Type, Authorization, X-Device-Type"

# Security Headers
Header always set X-Content-Type-Options nosniff
Header always set X-Frame-Options DENY
Header always set X-XSS-Protection "1; mode=block"

# Disable PHP error display in production
php_flag display_errors off
php_value error_reporting 0
⚠️ Important: .htaccess sirf Apache per kaam karta hai (cPanel/XAMPP). Nginx per alag config chahiye (upar dekhin).

🔒 Production Security Checklist

✅ Zaruri Steps

1

.env never public nahi hona chahiye

Upar .htaccess mein <Files ".env"> Deny from all lagao

2

JWT_SECRET strong banao

Kam az kam 64 characters ka random string: openssl rand -base64 64

3

HTTPS / SSL zarur lagao

cPanel → SSL → Let's Encrypt (Free) ya certbot

4

APP_DEBUG=false production mein

Error messages mein sensitive info show hoti hai

5

DB passwords strong rakho

Database user ke liye sirf alqalam database ka access do

6

Regular Backup

cPanel → Backup → Weekly automatic backup enable karo. Ya: mysqldump alqalam_db > backup_$(date +%Y%m%d).sql

⛔ Kabhi mat karo: .env file ko Git mein commit mat karo. Database password public_html mein hardcode mat karo. root MySQL user ko directly use mat karo.

ALLOWED_ORIGINS (CORS Lock)

# .env mein add karo production ke liye:
ALLOWED_ORIGINS=https://alqalam.edu.pk,https://www.alqalam.edu.pk

# PHP backend mein ye already handle hota hai:
# header("Access-Control-Allow-Origin: " . env('ALLOWED_ORIGINS','*'));
